# contact-groups Specification

## Purpose
Помогает разложить контакты по кругам общения: пользователь сам заводит группы, включает в них людей и смотрит контакты одной группы.

## Requirements

### Requirement: Название группы
Название группы SHALL быть длиной от 1 до 50 символов после обрезки пробелов по краям. Названия, отличающиеся только регистром, SHALL считаться одним названием в пределах групп одного пользователя. У разных пользователей названия групп SHALL не зависеть друг от друга.

#### Scenario: Пустое название
- **WHEN** пользователь отправляет название из одних пробелов
- **THEN** приложение показывает «Укажите название», группа не создаётся

#### Scenario: Слишком длинное название
- **WHEN** пользователь отправляет название длиннее 50 символов
- **THEN** приложение показывает «Слишком длинно: не больше 50 символов», группа не создаётся

#### Scenario: Такое же название у другого пользователя
- **GIVEN** у пользователя A есть группа «Теннис»
- **WHEN** пользователь B вводит в карточке своего контакта «теннис»
- **THEN** у B создаётся своя группа, контакт B в ней, а группа A не меняется

### Requirement: Создание группы в карточке контакта
В карточке контакта SHALL быть поле для новой группы. Введённое название SHALL создавать группу и сразу включать в неё контакт. Если группа с таким названием уже есть, контакт SHALL включаться в неё, новая группа не создаётся.

#### Scenario: Новая группа
- **WHEN** пользователь вводит в карточке «Теннис» и подтверждает
- **THEN** группа создана, контакт в ней, поле очищено

#### Scenario: Такая группа уже есть
- **GIVEN** есть группа «Теннис»
- **WHEN** пользователь вводит в карточке другого контакта «теннис»
- **THEN** контакт включён в группу «Теннис», второй такой группы нет

### Requirement: Состав групп меняется в карточке контакта
В карточке контакта SHALL быть видны все группы, те, в которых контакт состоит, отмечены. Нажатие на группу SHALL включать или исключать контакт. Изменение SHALL быть видно сразу и сохраняться без отдельной кнопки. Контакт SHALL мочь входить в несколько групп.

#### Scenario: Включить контакт в группу
- **GIVEN** контакт не состоит в группе «Семья»
- **WHEN** пользователь нажимает на неё в карточке
- **THEN** группа сразу отмечена и остаётся отмеченной после перезагрузки страницы

#### Scenario: Исключить контакт из группы
- **GIVEN** контакт состоит в группе «Семья»
- **WHEN** пользователь нажимает на неё в карточке
- **THEN** отметка снята и не возвращается после перезагрузки страницы

#### Scenario: Несколько групп
- **WHEN** пользователь включает контакт в группы «Семья» и «Теннис»
- **THEN** контакт отмечен в обеих и виден в каждой из них

#### Scenario: Контакт удалён в другой вкладке
- **GIVEN** карточка открыта, а контакт удалён в другой вкладке
- **WHEN** пользователь нажимает на группу
- **THEN** приложение сообщает «Контакт не найден»

#### Scenario: Удаление контакта
- **GIVEN** контакт состоит в группе «Семья»
- **WHEN** контакт удалён
- **THEN** группа остаётся, в ней на одного человека меньше

### Requirement: Контакты группы на главной
Если есть хотя бы одна группа, над списком контактов SHALL быть ряд кнопок: «Все» и кнопка на каждую группу с числом людей, по алфавиту. Нажатие на группу SHALL оставлять в списке только её контакты, выбранная кнопка выделена. Поиск SHALL работать внутри выбранной группы.

#### Scenario: Групп нет
- **GIVEN** ни одной группы нет
- **WHEN** пользователь открывает главную
- **THEN** ряда кнопок нет, главная выглядит как раньше

#### Scenario: Выбрать группу
- **GIVEN** в группе «Теннис» 2 контакта
- **WHEN** пользователь нажимает «Теннис 2»
- **THEN** в списке только эти 2 контакта, над списком «2 контакта», кнопка выделена

#### Scenario: В группе пока никого
- **GIVEN** группа есть, но в ней нет контактов
- **WHEN** пользователь нажимает на неё
- **THEN** вместо списка сообщение «В этой группе пока никого»

#### Scenario: Вернуться ко всем
- **GIVEN** выбрана группа
- **WHEN** пользователь нажимает «Все»
- **THEN** в списке снова все контакты

#### Scenario: Поиск внутри группы
- **GIVEN** выбрана группа «Теннис» из 2 контактов
- **WHEN** пользователь ищет имя одного из них
- **THEN** в списке один контакт, над списком «Найдено: 1 из 2», группа остаётся выбранной

#### Scenario: Поиск имени не из группы
- **GIVEN** выбрана группа «Теннис»
- **WHEN** пользователь ищет имя контакта, которого в ней нет
- **THEN** контакт не найден, «Найдено: 0 из 2»

#### Scenario: Группа выбрана, блока «Пора связаться» нет
- **GIVEN** есть контакты, которым пора связаться
- **WHEN** пользователь выбирает группу
- **THEN** блока «Пора связаться» нет

#### Scenario: Адрес удалённой группы
- **GIVEN** группа удалена, а её адрес сохранён
- **WHEN** пользователь открывает этот адрес
- **THEN** показываются все контакты, ни одна группа не выделена

### Requirement: Метки групп в общем списке
В строке общего списка SHALL быть видны группы контакта по алфавиту. У контакта без групп меток SHALL не быть.

#### Scenario: Контакт в двух группах
- **GIVEN** контакт состоит в группах «Семья» и «Теннис»
- **WHEN** пользователь открывает список
- **THEN** в строке контакта видны метки «Семья» и «Теннис»

### Requirement: Переименование группы
На странице «Группы» SHALL быть видны все группы с числом людей. Группу SHALL можно переименовать на месте; правила названия те же. Переименовать в название другой группы SHALL нельзя.

#### Scenario: Переименовать
- **WHEN** пользователь меняет «Тенис» на «Теннис» и подтверждает
- **THEN** группа называется «Теннис» на всех экранах, контакты остались в ней

#### Scenario: Название занято
- **GIVEN** есть группа «Семья»
- **WHEN** пользователь переименовывает другую группу в «семья»
- **THEN** приложение показывает «Такая группа уже есть», название не меняется

#### Scenario: Сменить только регистр
- **WHEN** пользователь меняет «теннис» на «Теннис»
- **THEN** название меняется

#### Scenario: Группа удалена в другой вкладке
- **GIVEN** страница открыта, а группа удалена в другой вкладке
- **WHEN** пользователь сохраняет новое название
- **THEN** приложение показывает «Группа не найдена»

### Requirement: Удаление группы
Группу SHALL можно удалить на странице «Группы» только после подтверждения. Контакты SHALL оставаться, из них пропадает только эта группа.

#### Scenario: Удалить группу
- **GIVEN** в группе «Теннис» 2 контакта
- **WHEN** пользователь удаляет её и подтверждает
- **THEN** группы нет, оба контакта на месте, метки «Теннис» у них нет

#### Scenario: Передумать
- **WHEN** пользователь нажимает удалить и в окне выбирает «Отмена»
- **THEN** группа на месте

### Requirement: Страница «Группы» без групп
Если групп нет, страница «Группы» SHALL показывать, что их создают в карточке контакта.

#### Scenario: Групп ещё нет
- **GIVEN** ни одной группы нет
- **WHEN** пользователь открывает страницу «Группы»
- **THEN** видно сообщение, что группы создаются в карточке контакта

### Requirement: Тестовые группы
При заполнении пустой базы тестовыми контактами SHALL создаваться группы Семья, Друзья, Знакомые, Теннис, Аналитики у пользователя с почтой владельца, и примерно треть его контактов SHALL получать одну или две из них. Для уже заполненной базы SHALL быть разовая команда, которая ничего не меняет, если хотя бы одна группа уже есть.

#### Scenario: Новая тестовая база
- **WHEN** пустая база заполняется тестовыми контактами
- **THEN** у владельца есть 5 групп и примерно треть его контактов состоит хотя бы в одной

#### Scenario: Разовая команда не трогает группы пользователя
- **GIVEN** хотя бы одна группа уже есть
- **WHEN** запускается разовая команда
- **THEN** она ничего не меняет и сообщает, что группы уже есть

# Spec Delta

## MODIFIED Requirements

### Requirement: Название группы
Название группы SHALL быть длиной от 1 до 50 символов после обрезки пробелов по краям. Названия, отличающиеся только регистром, SHALL считаться одним названием в пределах групп одного пользователя. У разных пользователей названия групп SHALL не зависеть друг от друга.

#### Scenario: Пустое название
- **WHEN** пользователь отправляет название из одних пробелов
- **THEN** приложение показывает «Укажите название», группа не создаётся

#### Scenario: Слишком длинное название
- **WHEN** пользователь отправляет название длиннее 50 символов
- **THEN** приложение показывает «Слишком длинно: не больше 50 символов», группа не создаётся

#### Scenario: Такое же название у другого пользователя
- **GIVEN** у пользователя A есть группа «Теннис»
- **WHEN** пользователь B вводит в карточке своего контакта «теннис»
- **THEN** у B создаётся своя группа, контакт B в ней, а группа A не меняется

### Requirement: Тестовые группы
При заполнении пустой базы тестовыми контактами SHALL создаваться группы Семья, Друзья, Знакомые, Теннис, Аналитики у пользователя с почтой владельца, и примерно треть его контактов SHALL получать одну или две из них. Для уже заполненной базы SHALL быть разовая команда, которая ничего не меняет, если хотя бы одна группа уже есть.

#### Scenario: Новая тестовая база
- **WHEN** пустая база заполняется тестовыми контактами
- **THEN** у владельца есть 5 групп и примерно треть его контактов состоит хотя бы в одной

#### Scenario: Разовая команда не трогает группы пользователя
- **GIVEN** хотя бы одна группа уже есть
- **WHEN** запускается разовая команда
- **THEN** она ничего не меняет и сообщает, что группы уже есть
